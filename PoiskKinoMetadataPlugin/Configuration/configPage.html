API-ключ можно получить на poiskkino.dev. Демо-ключ ограничен 200 запросами в сутки.
По умолчанию используется https://api.poiskkino.dev. Если сервер Jellyfin находится вне РФ или основной адрес недоступен из вашей сети — укажите https://eu-api.poiskkino.dev: токен и методы те же. Схему https:// можно не указывать, завершающий / не нужен, путь после хоста не поддерживается. Изменение применяется после перезапуска Jellyfin.
Включите эту опцию, если у вас проблемы с доступом к TMDB (региональные ограничения). Будут использоваться только изображения с других доменов.
