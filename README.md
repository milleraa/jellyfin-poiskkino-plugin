# PoiskKino Metadata Plugin для Jellyfin

Плагин для Jellyfin 12.x (.NET 10), который предоставляет метаданные фильмов и сериалов на русском языке через API [ПоискКино](https://poiskkino.dev).

## Возможности

- ✅ Получение метаданных для фильмов (IMovieMetadataProvider)
- ✅ Получение метаданных для сериалов (ISeriesMetadataProvider)
- ✅ Русские названия, описания и жанры
- ✅ Рейтинги КиноПоиск и IMDb
- ✅ Постеры и фоновые изображения (IImageProvider)
- ✅ Кэширование запросов для соблюдения лимита API (200 запросов/сутки)
- ✅ Обработка ошибок (403 Forbidden, 429 Too Many Requests, 404, таймауты)
- ✅ Настройка API-ключа и базового адреса API через веб-интерфейс Jellyfin

## Планируемые возможности

- 🔲 Провайдер метаданных для персон (IPersonMetadataProvider)
  - Отдельные страницы персон (актеры, режиссеры и т.д.)
  - Биографии и дополнительная информация
  - Фильмография актеров
  - Поиск персон по имени

## Требования

- Jellyfin 12.x (сборка против plugin API 12.0.0; Jellyfin 12 перешёл на .NET 10 и новый plugin ABI)
- .NET 10 SDK

> Релизы начиная с `v2026.11.22` — только для Jellyfin 12.x (.NET 10). Для Jellyfin 10.11.x используйте последний релиз `v2026.10.30` (собран под `net9.0` и API 10.11.5).

## Установка

1. Соберите проект:
   ```bash
   dotnet build -c Release
   ```

2. Скопируйте скомпилированную библиотеку (`PoiskKinoMetadataPlugin.dll`) в директорию плагинов Jellyfin:
   - Linux: `/var/lib/jellyfin/plugins/`
   - Windows: `%ProgramData%\Jellyfin\Server\plugins\`
   - Docker: `/config/plugins/`

3. Перезапустите Jellyfin

## Настройка

1. Перейдите в **Dashboard** → **Plugins** → **PoiskKino Metadata**
2. Введите ваш API-ключ от ПоискКино
3. Проверьте поле **Базовый URL API** — по умолчанию `https://api.poiskkino.dev`; менять не нужно, если сервер Jellyfin находится в РФ
4. Сохраните настройки

**Изменение базового URL API применяется после перезапуска Jellyfin.**

### Получение API-ключа

API-ключ можно получить на [poiskkino.dev](https://poiskkino.dev). Демо-ключ ограничен 200 запросами в сутки.

### Базовый URL API

Поле **Базовый URL API** задаёт адрес, по которому плагин обращается к API ПоискКино. Это поле свободного ввода: известные адреса предлагаются как подсказка, но ввод не ограничен.

- По умолчанию — `https://api.poiskkino.dev`. Если сервер Jellyfin находится в РФ и этот адрес доступен, менять значение не нужно.
- Если сервер Jellyfin находится вне РФ или основной адрес недоступен из вашей сети — укажите зеркало `https://eu-api.poiskkino.dev`: токен и методы те же. Важно, чтобы адрес был доступен **с сервера Jellyfin**, а не из браузера администратора.
- **Изменение применяется после перезапуска Jellyfin.**
- Фактический базовый адрес пишется в лог плагина при создании клиента: `PoiskKino API base URL: …`.

Значение нормализуется на стороне плагина:

- схему `https://` можно не указывать — она подставится автоматически (`eu-api.poiskkino.dev` → `https://eu-api.poiskkino.dev`);
- завершающий `/` не нужен;
- поддерживается только `https`: `http://`, `ftp://` и другие схемы отклоняются;
- путь после хоста не поддерживается (`https://proxy.corp/poiskkino`); также отклоняются адреса с логином/паролем (`user:password@…`), параметрами (`?…`) и якорем (`#…`);
- пустое поле означает адрес по умолчанию — это не ошибка;
- если значение невалидно, плагин использует адрес по умолчанию и пишет предупреждение с причиной в лог (`Invalid API base URL … falling back to …`), поиск продолжает работать.

Сохранённое значение не переписывается: в конфигурации остаётся то, что ввёл администратор, а нормализация применяется при создании клиента.

## API ПоискКино

Документация API: https://api.poiskkino.dev/documentation-json

Базовый адрес настраивается (см. [«Базовый URL API»](#базовый-url-api)): по умолчанию `https://api.poiskkino.dev`, зеркало — `https://eu-api.poiskkino.dev`.

Пример запроса (для основного адреса; при настроенном базовом адресе хост будет соответствующим):
```
GET https://api.poiskkino.dev/v1.5/movie/search?query={title}&limit=3
Headers:
  X-API-KEY: ваш_api_ключ
```

## Особенности реализации

### Кэширование

Плагин кэширует результаты поиска на 24 часа по ключу `название:год` для минимизации запросов к API и соблюдения лимита 200 запросов в сутки.

### Обработка ошибок

- **403 Forbidden / 429 Too Many Requests**: Логируется предупреждение с сообщением от API (превышен суточный лимит)
- **404 Not Found**: Результат кэшируется на 1 час (чтобы не повторять неуспешные запросы)
- **Таймауты**: Логируются как предупреждения

### Потокобезопасность

Все классы используют потокобезопасные структуры данных:
- `ConcurrentDictionary` для кэша
- `SemaphoreSlim` для синхронизации запросов
- `HttpClient` через `IHttpClientFactory` (регистрируется Jellyfin)
