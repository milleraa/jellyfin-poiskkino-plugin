## Описание

Заменить обе рефлексивные проверки `GetPersonKind_VariousProfessions_MapsCorrectly` проверками наблюдаемого результата `GetMetadata` с подменой ответа API. Зафиксировать основания для удаления по `test-audit` до правок.

## Acceptance criteria

1. Каждый провайдер проверяется через `GetMetadata`: фактическая персона в `result.People` имеет ожидаемый `PersonKind`, включая роли, отличные от Actor. Не потерян ни один сценарий удаляемых таблиц, включая проверявшиеся варианты языка, регистра и значения по умолчанию.
2. Каждый провайдер проверяет профессию только в английском поле: `Profession` отсутствует, `EnProfession` содержит распознаваемую неактёрскую профессию. Проверка наблюдает выход провайдера, а не самостоятельно маппящую подмену.
3. Не дублировать существующие публичные проверки без отдельного риска: если затрагивается `GetMetadata_MapsPersons` фильмов, сохранить его самостоятельные утверждения. Нет рефлексии или изменений production API ради тестов.
4. В изолированной копии при принудительном `PersonKind.Actor` в результирующем маппинге серий новый тест падает на сравнении роли. После восстановления проходит полный `dotnet test`.

## Технические заметки

После локального коммита и приёмки [001](001-series-search-year.md); обе задачи меняют тесты сериалов. Два публичных входа проверяются отдельно: потеря роли у одного провайдера не гарантирует сбой у второго.
