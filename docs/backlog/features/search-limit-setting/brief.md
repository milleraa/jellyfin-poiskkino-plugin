# Brief — `search-limit-setting`

## Цель

Сделать количество результатов поиска (сейчас жёстко задано `limit=3` в `PoiskKinoApiClient.SearchAsync`, `PoiskKinoApiClient.cs:105`) настраиваемым параметром плагина, чтобы администратор мог получать больше подсказок при ручной идентификации фильмов и сериалов в Jellyfin.

## Scope (in)

- Новое свойство в `PluginConfiguration` (например `SearchLimit`), значение по умолчанию — `3` (сохранение текущего поведения).
- Поле на странице конфигурации плагина (HTML) с валидацией диапазона (диапазон уточнит Техлид, ориентир 1–10).
- Проброс значения в `PoiskKinoApiClient.SearchAsync` вместо хардкода `limit=3`.
- Учёт лимита в ключе кэша поиска (`search:{title}:{year}`), либо осознанное решение принять устаревание кэша после смены настройки — определят Архитектор/Техлид.
- Юнит-тесты на новое поведение.

## Out of scope

- Изменение эндпоинта поиска `/v1.5/movie/search` и его параметров кроме `limit`.
- Пагинация или повторные запросы за пределами одной страницы результатов.
- Настройки фильтрации по году (`SearchYearFilter`) — не меняются.
