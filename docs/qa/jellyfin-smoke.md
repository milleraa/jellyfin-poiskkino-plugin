# Ручная проверка в Jellyfin

Выберите сценарии, на которые влияет изменение. Нужны Jellyfin 12.x, сборка плагина с проверяемого коммита и действующий ключ ПоискКино для сетевых сценариев. Для установки следуйте [README](../../README.md).

1. Откройте настройки плагина в панели Jellyfin. Проверьте отображение и сохранение изменённых параметров; если для их применения нужен перезапуск, перезапустите Jellyfin и проверьте результат.
2. Для изменений провайдеров идентифицируйте фильм или сериал в Jellyfin. Проверьте затронутые метаданные и изображения на подходящем примере.
3. При изменении API-клиента проверяйте только нужные сценарии и учитывайте лимит запросов для демо-ключа. Не записывайте ключ в отчёт или логи.

Укажите коммит, среду, ожидаемый и фактический результат в `qa.md` и [журнале прогонов](test-runs.md). Если среда или ключ недоступны, отметьте, что соответствующие сценарии не проверены.
