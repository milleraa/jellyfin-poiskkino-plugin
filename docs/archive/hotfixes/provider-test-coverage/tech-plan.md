# Tech plan — покрытие поведения провайдеров

Владелец: **Техлид**. Ветка: `hotfix/provider-test-coverage`.

Входы: [incident.md](incident.md), [root-cause.md](root-cause.md), [ADR-0001](../../../architecture/decisions/ADR-0001-search-year-filter.md). Отдельный архитектурный этап не нужен: меняются только тесты.

## Порядок выполнения

| Шаг | Задача | Исполнитель | Зависимость |
|-----|--------|-------------|-------------|
| 1 | [001 — Поиск сериалов по году](tasks/001-series-search-year.md) | `developer-csharp` | Нет |
| 2 | [002 — Роли персон в метаданных](tasks/002-metadata-person-roles.md) | `developer-csharp` | Локальный commit и приёмка 001 Техлидом; обе задачи затрагивают файл тестов сериалов |

Работа строго последовательная в одной ветке, без task-branches. Техлид проверяет локальные коммиты, выполняет ревью по `test-audit`, проверяет чувствительность к двум регрессиям в изолированной копии и полный `dotnet test` на чистом коде. DevOps impact check завершается по итоговому diff до приёмки и передачи Оркестратору для QA. Push не выполняется.

## Границы

Изменяются только тесты провайдеров фильмов и сериалов и артефакты hotfix. Вне объёма: код плагина, другие тестовые файлы, настройки, CI, упаковка и установка. Намеренные поломки не попадают в рабочую ветку.
